# Amane: руководство

Перевод книги-документации **Amane** на русский язык с проверкой по исходному коду.

- Оригинал: <https://mystiafin.github.io/amane/>
- Исходники: <https://github.com/MystiaFin/amane>
- Репозиторий перевода: <https://github.com/wesdyqq/amane-ru>
- HTML-версия: <https://wesdyqq.github.io/amane-ru/>
- Проверенная версия: **0.1.2**, Rust edition 2024
- Дата сверки: **19 октября 2026 года**

Amane — библиотека на Rust для создания собственной оболочки Wayland: панелей, баров, лаунчеров, всплывающих уведомлений и экранов блокировки. Вся оболочка пишется как одна программа на Rust. Она подключается напрямую к композитору и рисует через GPU, без браузерного движка, QML и GTK.

> **Статус проекта.** В README репозитория сказано, что разработка приостановлена до середины декабря 2026 года, а новые issue и pull request пока не принимаются. Код версии 0.1.2 при этом полностью работоспособен. Документация ниже описывает именно эту версию.

## Как читать

Книга разделена на шесть частей. Внутри сохранён порядок и названия глав оригинала; код и имена API оставлены на английском, чтобы примеры можно было копировать без изменений.

1. [Начало работы](01-start.md) — введение, шпаргалка, установка, первая оболочка, команда `amane`.
2. [Основные понятия](02-core.md) — представления, слойные окна, компоновка, масштабирование, сервисы, ввод, анимация.
3. [Виджеты](03-widgets.md) — `Rectangle`, `Text`, `TextInput`, `ScrollArea`, `Canvas`, изображения, шейдеры.
4. [Дополнительные окна](04-windows.md) — несколько окон и мониторов, обычные окна, экран блокировки.
5. [Встроенные сервисы](05-services.md) — система, звук, сеть, Bluetooth, медиа, уведомления, рабочие столы, приложения, палитра, PAM.
6. [Интеграция с системой](06-system.md) — команды и файлы, IPC, D-Bus, поиск неисправностей.

Полный текст книги одним файлом: [amane-ru.md](amane-ru.md).

## HTML-версия

Собранная книга в том же виде, что и оригинальный сайт (mdBook, стандартная тема): откройте [html/index.html](html/index.html). Исходники для mdBook лежат в `book/`; пересобрать можно командой `mdbook build book` (использован mdBook 0.5.4 — та же версия, что и на оригинальном сайте).

## Что исправлено

При переводе я сверял утверждения книги с исходниками. Найденные расхождения перечислены в [CORRECTIONS.md](CORRECTIONS.md), а в тексте отмечены блоками:

> **Исправление.** Здесь оригинал ошибался.

> **Уточнение.** Здесь оригинал был прав, но опускал важную деталь.

Основные исправления касаются:

- значения по умолчанию у `Window::resizable`;
- очистки парольного `TextInput` после Enter;
- поведения `Palette` до загрузки изображения;
- кодов возврата и потоков вывода у `output` и `lines`;
- реакции `watch_file` на удаление файла;
- неполного списка системных зависимостей;
- поведения `amane new` при заданном `AMANE_CONFIG`;
- устаревшей команды `amane startup`;
- поведения `.focused()` у `TextInput` и `on_change` при `set_text`;
- кэша изображений и `Image::loaded`;
- разметки в тексте уведомлений;
- специальных рабочих столов Hyprland и тегов Mango;
- интервала опроса `Brightness` и других сервисов;
- типа обработчиков у `App::ipc` и `App::window`;
- семантики `Battery::full()`;
- радиального градиента до углов;
- блокировок `Service::read()`/`write()` и перезапуска после паники в `listen`;
- вывода `amane run`, поведения `amane clean` и `amane restart`;
- опечатки «optimised shell» в справке CLI.

Полный список из 27 пунктов — в [CORRECTIONS.md](CORRECTIONS.md).

## Предположения

Примеры предполагают:

- Linux и Wayland-композитор с поддержкой `wlr-layer-shell` (niri, Hyprland, Sway, river и другие);
- установленный Vulkan-драйвер;
- Rust и C-компилятор для сборки;
- конфигурацию в `~/.config/amane` (или `$XDG_CONFIG_HOME/amane`), если не указано иное.

Примеры не проверялись на живой сессии композитора в рамках перевода: они сверены с исходным кодом и типами API. Если пример меняет состояние системы (звук, сеть, блокировку), сначала прочитайте пояснение рядом с ним.
